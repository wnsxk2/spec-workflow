사용자가 스펙이나 티켓으로 설명한 작업을 구현한다.

사용자가 티켓 참조를 넘기면 이슈 트래커에서 해당 티켓을 가져와, 시작하기 전에 제목을 밝힌다. 참조가 모호하면 질문한다.

가능한 곳에서는 미리 합의한 시임(seam)에서 Skill 도구로 "tdd"를 호출한다.

타입 검사는 수시로, 단일 테스트 파일은 수시로 실행하고, 전체 테스트 스위트는 마지막에 한 번 실행한다.

작업을 마치면 Skill 도구로 "code-review-matt"를 호출해 작업을 리뷰한다.

작업 내용을 현재 브랜치에 커밋한다.
