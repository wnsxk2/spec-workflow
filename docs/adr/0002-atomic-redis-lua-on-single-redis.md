# 세션과 로그인 차단 기록은 Lua 스크립트로 한 번에 바꾸고, Redis는 한 대를 전제로 한다

토큰 교환, 세션 폐기, 로그인 차단 기록처럼 읽고 고치는 일이 겹치는 동작은 Redis 안에서 한 번에 실행되는 Lua 스크립트 하나로 처리한다. 그래서 같은 Refresh Token으로 동시에 요청해도 교환은 한 번만 일어난다. 스크립트는 색인에서 찾은 세션 id로 키를 만들기 때문에 Redis 클러스터(여러 대에 나눠 저장하는 구성)에서는 동작하지 않는다. 낙관적 잠금(MULTI/WATCH로 충돌하면 다시 시도)과 클러스터에서도 되는 키 설계를 검토했지만, 다시 시도 없이 단순하게 원자성을 얻기 위해 한 대의 Redis를 전제로 했다.

## 결과

- Redis를 여러 대로 나누려면 한 세션의 키들이 같은 곳에 저장되도록 키 설계와 스크립트를 다시 만들어야 한다.
