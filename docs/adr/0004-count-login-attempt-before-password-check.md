# 로그인 시도는 비밀번호를 대조하기 전에 센다

로그인 차단을 위한 실패 횟수는 실패한 뒤에 세지 않는다. 비밀번호를 대조하기 전에 이번 시도를 실패로 미리 세고, 로그인에 성공하면 그 기록을 지운다. 로그인 차단인지 확인하는 일과 실패를 기록하는 일을 따로 하면, 4번 실패한 상태에서 동시에 보낸 요청들이 모두 확인을 통과해 비밀번호를 5번 넘게 찍어 볼 수 있기 때문이다.

## 결과

- 5번째 시도를 확인하는 동안 동시에 들어온 다른 시도는 올바른 비밀번호여도 로그인 차단(429)으로 거절된다.
- 로그인 차단 중의 시도는 기록을 바꾸지 않으므로, 차단 중에 계속 시도해도 차단 기간이 늘어나지 않는다.
